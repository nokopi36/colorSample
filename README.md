# O Color Design

装具の配色見本を作る Android アプリ。

装具（ブレース・義足など）は革・プラスチック・スポンジ・糸・ボタンといった素材ごとに色を選べます。
このアプリはパーツごとに色を当てた見本をその場で描き、氏名を添えて保存・共有できるようにします。
装具士と利用者のあいだで「どの色で作るか」を突き合わせるためのものです。

## できること

**配色を決める**

組み込みの6装具（ナイトブレース / フットプレート / SLB / プレーリーくん / ポーゴスティック / Aブレース）
から選び、パーツごとに色を指定します。プレビューは操作しながら即座に更新されます。
氏名を入れると見本に焼き込まれます。

- **保存** — 端末のギャラリーに PNG で保存
- **共有** — 他アプリへ画像を渡す
- **リセット** — 全パーツを初期色に戻す（氏名は残る）

**色を増やす・減らす**

組み込みは9グループ・26色ですが、現場で使う色に合わせて変えられます。

- 色の追加・編集 — 色相/彩度/明度のスライダーと 16進入力の両方で指定でき、双方向に連動します。
  指定書の色番号をそのまま入れられます
- 組み込み色の非表示 — 使わない色を一覧から外せます。**グループ単位**なので「革の白は外すが
  ボタンの白は残す」ができます。定義自体は消えないのでいつでも戻せます
- 色グループの追加 — 「マジックテープ」のような素材区分そのものを増やせます

**自分の装具を登録する**

透過PNG のパーツ画像を取り込んで、独自の装具を作れます。作った装具は編集・削除でき、
組み込みの装具も一覧から非表示にできます。

パーツ画像には条件があります。

| 条件 | 補足 |
|---|---|
| 透過PNG | JPEG など透明を持たない形式は使えません |
| 全レイヤーが同じ寸法 | 重ねて描くため、揃っていないと位置が合いません |
| 色を変える層はベタ塗りのシルエット | 描画時に単色で塗るので、陰影を描いても失われます |
| 長辺 1440px 以内 | 超える画像は自動で縮小されます |

輪郭を描いた線画などは「色を変えない」に設定します。何枚でも置けて、色を変える層のあいだに
挟むこともできます。

## 対応環境

- **Android 6.0 (API 23) 以上**
- 縦向き・横向きの両方に対応
- ダークテーマ対応（ただし配色プレビューの下地は色を見比べやすいよう常に明色で固定）

> Android 5.x (API 21–22) は対象外です。Navigation 3 が要求する Compose のバージョンが
> minSdk 23 以上を必要とするためです。

## ビルド

```bash
./gradlew assembleDebug        # デバッグビルド
./gradlew assembleRelease      # リリースビルド
./gradlew testDebugUnitTest    # ユニットテスト
./gradlew lintDebug            # lint（エラーがあるとビルドを止めます）
```

依存とバージョンは `gradle/libs.versions.toml` に集約しています。**バージョンの正はここだけ**なので、
このファイルを見てください。バージョンを上げる際の制約は `CLAUDE.md` に書いてあります。

## 技術スタック

- **Kotlin** / **Jetpack Compose** + Material3（XML レイアウトと DataBinding は使っていません）
- **Navigation 3** (`androidx.navigation3`) / 単一 Activity
- **DataStore** + kotlinx.serialization でユーザーが追加した色と装具を保存
- Gradle KTS + バージョンカタログ

## 構成

```
com.nokopi.colorsample/
├── MainActivity.kt            アプリ唯一の Activity
├── navigation/                遷移先のキーと NavDisplay
├── data/
│   ├── BuiltInCatalog.kt      組み込みの色と装具の定義
│   ├── CatalogMerger.kt       組み込みとユーザー定義のマージ
│   ├── CatalogRepository.kt   画面が見るカタログの入り口
│   ├── model/                 実行時モデル
│   └── store/                 保存形式
├── ui/
│   ├── home/                  装具の一覧
│   ├── device/                配色画面（全装具で共用）
│   ├── palette/               色の管理
│   ├── deviceeditor/          装具の作成・編集
│   └── theme/                 Material3 テーマ
└── util/                      画像の保存・共有
```

6装具の画面は**すべて同じ1画面**です。違いはパーツ数・画像・ラベル・使える色だけで、
それはカタログのデータに閉じています。装具を増やすのはデータを足すだけの作業です。

## ドキュメントの住み分け

- **README.md**（このファイル）— 何のアプリで、何ができて、どう動かすか
- **CLAUDE.md** — コードを編集する前に知らないと事故る事実。守るべき不変条件、
  過去に踏んだ罠とその防ぎ方、バージョンを上げるときの制約

技術的な内容でも、性質で分けています。「Compose を使っている」は README、
「パレットは必ず1色以上でなければ落ちる」は CLAUDE.md です。
バージョン番号はどちらにも書かず `gradle/libs.versions.toml` を唯一の情報源にしています。

## テスト

ユニットテスト133件。装具・色の定義、マージ処理、画像取り込みの検証、状態遷移を押さえています。
組み込みの定義は Compose 移行前のソースから独立に書き起こした期待値で固定してあり、
パーツの取りこぼしや色の並び替えが起きたら落ちます。
